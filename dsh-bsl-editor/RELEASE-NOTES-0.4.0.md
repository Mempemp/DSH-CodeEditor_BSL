# dsh-bsl-editor v0.4.0

## Новое

- **Перехват открытия файлов из чата для `.bsl` и `.xml`** — обёртка над `remote.session.openWorkspacePath`, единственной фуннелью чата в dsh 0.1.2: ссылки на модули и XML-описания открываются во вкладке Editor, файлы других форматов уходят дальше (dsh-better-sidebar, затем система). Успешный перехват возвращает remote-конверт `{ ok, value }`, обёртка переустанавливается, если другой плагин поставил свою поверх.
- **Файлы, которых ещё нет в git, видны в «Изменённых»** — `git status` запрашивается с `--untracked-files=all`: новые файлы перечисляются поштучно и помечаются `+` в дереве и в списке; свёрнутых строк вида `?? Каталог/` больше нет.
- **Поиск в «Изменённых» идёт по пути файла, а не только по имени** — запрос находит `Module.bsl` внутри `Forms/ФормаЗагрузки`; совпадения по имени ранжируются выше совпадений по пути.
- **Новый файл в редакторе показывается как полностью добавленный** — при пустом diff от git строки помечаются как добавленные, в панели навигации подпись «новый файл».
- **Диагностика F12 в консоли** — если файл не BSL или определение не найдено, печатается строка с именем символа и путём файла.

## Исправления

- **Открытие файлов из чата не работало на dsh 0.1.2** — перехват был установлен на `ctx.workspaces.openPath`, который новый чат не вызывает. Относительные пути из чата резолвятся от cwd активной сессии.
- **Бейджи дерева и список «Изменённые» не обновлялись после `Ctrl+S`** — сохранение перечитывает git-статусы на клиенте, хост сбрасывает свой кэш статусов при записи файла.
- **Кэш git-статуса мог отдать состояние до сохранения** — запись файла сбрасывает кэш и помечает устаревшим индекс имён для поиска.
- **Поиск не находил файл по части пути** — фильтр работал только по имени файла.

## Прочее

- README: раздел про переход к определению приведён к текущему поведению F12, добавлены бейдж `+` и подпись «новый файл», обновлены ссылки установки.
