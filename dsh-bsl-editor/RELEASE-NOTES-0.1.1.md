# dsh-bsl-editor v0.1.1

## Вкладки редактора

- Верхний бар стал полосой вкладок: каждый открытый файл — своя вкладка с именем, индикатором несохранённых правок (●) и кнопкой закрытия (✕ или средняя кнопка мыши — как в браузере).
- Переключение вкладок мгновенное и без потерь: текст правок, позиция курсора и скролл сохраняются per-tab (буферы Monaco + view-state).
- Несохранённые изменения переживают переключение чат ↔ Editor.
- Кнопки справа на таб-баре: «перечитать с диска» (сброс несохранённых правок) и «сохранить». Надпись статуса LSP убрана из бара.

## Фильтр изменённых файлов

- Два режима вместо дерева: «Все файлы» / «Изменённые» — плоский список файлов с git-статусом, цвет бейджа как в VS Code (M/A/D/?).
- Наведение на файл показывает полный путь; клик открывает файл во вкладке.
- Настройка в DSH Settings → «1С-редактор»: «Показывать в изменениях untracked-файлы» (по умолчанию выключено).

## Тема Monokai

- Палитра редактора заменена с VS Code Dark+ на Monokai (по оригинальной теме vscode theme-monokai): фон #272822, розовые ключевые слова, зелёные функции/классы, жёлтые строки, фиолетовые числа, голубые встроенные функции.

## Исправления

- Починена TM-раскраска после переключения чатов: повторная инициализация onigasm больше не ломает подсветку («Onigasm#init has been called…»).
- Один файл = одна вкладка независимо от способа открытия (дерево / поиск / список изменений): пути канонизируются.
- Активная вкладка корректно подсвечивается; последняя открытая вкладка восстанавливается при возврате в Editor вместе со скроллом и курсором.
- Правки при переключении вкладок больше не теряются и не затираются перечитыванием с диска.
