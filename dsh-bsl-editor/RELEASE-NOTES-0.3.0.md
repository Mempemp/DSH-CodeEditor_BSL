# dsh-bsl-editor v0.3.0

## Исправления

- **Вставка ссылки в чат на dsh ≥ 0.1.2** — пункт «Добавить к обсуждению» из контекстного меню редактора. В dsh 0.1.2 композер переведён на Lexical-редактор: вставка текста напрямую в DOM поля ввода больше не попадала в черновик (уведомление показывалось, текст в чат не уходил). Ссылка вставляется через provide-канал композера (`conversation.input`); при недоступности канала текст копируется в буфер обмена.

## Прочее

- **Название рабочего пространства** — `/bsl/workspaces` отдаёт `title` активного воркспейса (реестр либо имя папки); шапка дерева редактора обновляет название при переключении сессий.
