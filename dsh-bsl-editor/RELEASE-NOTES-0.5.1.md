# dsh-bsl-editor v0.5.1

## Новое

- **Раздел «Внешние отчеты/обработки» в дереве метаданных** — если в корне выгрузки есть папка `ExternalFiles`, в корне дерева появляется отдельный пункт (иконка папки, сразу после «Общие»). Объект — это `<Имя>.xml` (описание внешнего отчета/обработки) и папка `<Имя>/` с формами, макетами и модулем объекта; состав собирается как объединение описания и файловой системы (в выгрузках встречаются и папки без описания, и формы, которых нет в `<ChildObjects>`). Левый клик раскрывает объект (Реквизиты / Табличные части / Формы / Команды / Макеты / Модули), правый — открывает XML описания. Иконка объекта — отчёт или обработка по корневому элементу описания (`ExternalReport` / `ExternalDataProcessor`). Работает поверх любого из трёх форматов выгрузки; поиск и режим «Изменённые» знают про эти объекты.

## Исправления

- **Ссылки на файлы из чата снова открываются в редакторе.** В ядре 0.1.5 (DSH Desktop 0.9.0-1) чат отдаёт файл правому сайдбару вызовом `sidebarRight.openResource` с адресом `dsh-resource://file/…`; прежняя фуннель `remote.session.openWorkspacePath` больше не вызывается вообще, поэтому обёртка на ней молча ничего не перехватывала и файл уходил в better-sidebar. Плагин перехватывает и новую фуннель: `.bsl`/`.xml` открываются в редакторе с раскрытием дерева, остальные форматы уходят в сайдбар как раньше. Обёртки на `remote.session.openWorkspacePath` (ядро 0.1.2) и `workspaces.openPath` (ядра ≤ 0.1.1) сохранены — перехват работает на всех трёх.
- **Баннер «This document contains many ambiguous unicode characters» убран.** Monaco считает русские буквы «двусмысленными» (А/В/С/Е/О/Р/Х совпадают с латинскими) и «не базовым ASCII», поэтому плашка висела над каждым модулем с русскими комментариями и строками запросов. Обе проверки выключены корректной формой опции — `unicodeHighlight: { ambiguousCharacters: false, nonBasicASCII: false }`; подсветка невидимых символов (неразрывный пробел, zero-width) оставлена включённой: в 1С они тихо ломают код.
- **Кнопки «Перечитать с диска» и «Сохранить» перенесены в левый край полосы вкладок** — правый верхний угол панели занимает плашка MCP-менеджера и закрывала их. Кнопки закреплены `position: sticky; left: 0`, чтобы не уезжать при горизонтальной прокрутке ленты вкладок.
