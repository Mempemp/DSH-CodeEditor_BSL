# dsh-bsl-editor v0.2.0

## Просмотр диффов в редакторе

Изменения рабочей копии видны прямо в открытом файле:

- **Добавленные строки** подсвечиваются зелёным фоном с полосой слева.
- **Удалённые строки** показываются красными блоками между строками — с их текстом, как он был до изменения.

Для перемещения по изменениям:

- Панель в правом верхнем углу редактора: кнопки ↑ / ↓ и счётчик «текущий / всего».
- Хоткеи **Alt+↓** — следующее изменение, **Alt+↑** — предыдущее. Переход центрирует блок и подсвечивает его вспышкой.
- Счётчик считает не строки, а **блоки изменений**: несколько соседних изменённых строк — это одно изменение. Если проскроллить файл вручную, счётчик показывает, какой блок сейчас на экране.
- Файл с изменениями при открытии сразу позиционируется на первый блок.

## Открытие файлов из чата

Клик по ссылке на файл в сообщении чата (в результатах Read/Edit, в упоминаниях) открывает этот файл в редакторе плагина:

- дерево раскрывается до нужного файла, файл подсвечивается;
- активной становится вкладка Editor.

Пути вне workspace открываются как раньше — системным приложением.

По умолчанию перехват включён. Отключается в Settings → «1С-редактор» → «Перехватывать открытие файлов из чата». Если включён dsh-better-sidebar со своим перехватом — приоритет у этого плагина; после отключения настройки — снова у better-sidebar.

## Фильтр «Изменённые» в дереве метаданных

Режим «Изменённые» раньше работал только для дерева файлов. Теперь он работает и для дерева метаданных:

- остаются только группы типов и объекты, в которых есть изменённые файлы; счётчики у групп пересчитываются;
- поиск в этом режиме тоже ищет только по изменённым файлам.

Untracked-файлы (новые, ещё не добавленные в git) теперь попадают в «Изменённые» по умолчанию — новые внешние обработки видны сразу после создания. Отключается настройкой «Показывать в изменениях untracked-файлы».

## Автообновление открытых файлов

Если открытый во вкладке файл изменили вне редактора (агент, внешний редактор), вкладка подхватывает новое содержимое:

- при переключении на вкладку или возврате в окно DSH;
- если своих правок нет — файл обновляется сам, скролл и курсор сохраняются;
- если правки есть — содержимое не трогается: появляется плашка «Файл изменён на диске» с кнопкой «Перезагрузить с диска». Нажатие заменяет текст версией с диска.

## Мелочи

- «Добавить к обсуждению»: ссылка вставляется в композер с новой строки, а не приклеивается к набранному тексту.
- Операции, опрашивающие git-статусы (фильтр, поиск, дерево метаданных), используют кэш статусов на 5 секунд.
