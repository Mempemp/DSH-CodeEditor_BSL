# dsh-bsl-editor v0.2.1

## Исправления

- **Порча кодировки при сохранении** — тело запроса `/bsl/write` собиралось через конкатенацию строковых чанков: русские символы, разрезанные границей TCP-пакета, превращались в U+FFFD и записывались в файл. Тело собирается как Buffer и декодируется один раз.
- **Кодировка файла при чтении/записи** — кодировка определяется по байтам файла: строгий UTF-8, при невалидности — Windows-1251 (родная кодировка 1С:Конфигуратора). Запись выполняется в исходной кодировке, BOM восстанавливается по первым байтам файла.
- **Hot-reload открытых вкладок** — после перемонтирования вкладки Editor (переключение чат↔редактор) сверка с диском работала не всегда: утраченный mtime заменён на прямое сравнение контента.
- **F12-переход внутри модуля** — восстановление view-state при программной навигации затирало целевую позицию; теперь навигация отключает восстановление.
- **Навигация по диффам** — программный скролл при переходе по якорям больше не пересчитывает счётчик; текущим считается якорь, ближайший к центру видимой области.
- **Предупреждения Monaco в консоли** — `restoreViewState` обёрнут в try/catch (Canceled при быстрой смене модели).

## Прочее

- **Раскраска без CDN** — Monaco, onigasm, monaco-textmate и codicon.ttf поставляются в пакете и раздаются хостом (`/bsl/vendor`); CDN используется только как запасной вариант. Устранено зависание воркеров Monaco при локальной загрузке.
- **Смена рабочего пространства** — при переключении сессии в чате редактор перепривязывается к cwd активной сессии.
- **Диагностика сохранения** — в ответ `/bsl/write` добавлены `clientLen`/`clientRepl` (длина и число U+FFFD полученного контента).
